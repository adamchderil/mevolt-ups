# MeVolt UPS Monitor

Нативное Android-приложение для просмотра телеметрии UPSMON PRO и истории событий из любой сети. На телефоне не требуется Tailscale или другой VPN-клиент: приложение подключается к защищённому HTTPS-шлюзу на компьютере.

При запуске показывается заставка «Koval electronics» в течение 3 секунд. При первом запуске нужно войти в учётную запись; затем данные входа сохраняются в зашифрованном виде с ключом Android Keystore и автоматически восстанавливаются. Сервер проверяет учётные записи, созданные администратором; пароль администратора и пароли пользователей хранятся на компьютере только в виде PBKDF2-HMAC-SHA256-хешей с индивидуальными солями. Пользовательские данные, телеметрия и история передаются через HTTPS.

После входа приложение может отслеживать источник питания в фоновой службе. Android показывает постоянное уведомление службы с кнопкой остановки; тот же переключатель доступен в настройках подключения. Приложение запрашивает разрешение на уведомления. Проверяются переходы UPSMON PRO «нормальная сеть» (`utilityState=1`) и «сбой сети» (`utilityState=2`); неизвестные коды не вызывают тревогу. Мониторинг запускается после перезагрузки телефона, пока разрешены уведомления и приложение не было остановлено принудительно. Фоновый опрос увеличивает расход батареи.

## Удалённое подключение

Компьютер с UPSMON PRO должен оставаться включённым и подключённым к интернету.

1. На компьютере установите и подключите Tailscale. Телефон подключать к tailnet не нужно.
2. Убедитесь, что Funnel уже включён и его корневой маршрут на `http://127.0.0.1:3001` работает.
3. Из папки проекта запустите в PowerShell:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\Install-PublicUpsGateway.ps1
   ```

   Скрипт проверяет существующий маршрут `:3001`, запускает read-only шлюз на `127.0.0.1:8002`, добавляет отдельный Funnel-путь `/upsmon` и регистрирует шлюз в автозапуске Windows. Исходный корневой маршрут Funnel не меняется. На роутере не нужно открывать порты.

4. Убедитесь, что на компьютере запущен UPSMON PRO, его Web-сервер и доступен файл `ups.txt`.
5. Установите APK и войдите в учётную запись. Адрес сервера по умолчанию уже задан, поэтому вводить IP компьютера не нужно.

Публичный домен приложения: `https://win-pjghmomb24s.tail184144.ts.net/upsmon`. Шлюз публикует только чтение телеметрии и истории; команды управления через него не доступны. Все API-запросы требуют серверной авторизации. Создание пользователей разрешено только администратору и синхронизируется на сервере, поэтому пользователи могут входить с других устройств.

Файл серверных учётных записей находится в `%APPDATA%\MeVoltUpsMonitor\users.json`. Он создаётся при первом запуске шлюза. Скрипт установки запросит новый пароль администратора (не менее 12 символов); пароль не хранится в исходниках. Старые локальные аккаунты из версии 1.7 не переносятся автоматически: создайте их заново из вкладки «Пользователи» после входа администратора.

## Данные и история

Шлюз напрямую читает `ups.txt` из каталога веб-сервера UPSMON PRO и `EventRecord.CSV` из каталога данных UPSMON PRO (кодировка журнала Windows-1251). Он принимает только чтение данных и управление учётными записями администратором; команды управления ИБП не пересылаются. Если UPSMON PRO или компьютер выключены, мониторинг и история недоступны.

В приложении отображаются входное и выходное напряжение, нагрузка, входная и выходная частоты, заряд, режим AVR, источник питания и состояние ИБП. Вкладка «История» загружает оригинальные события из `EventRecord.CSV`.

Вкладки мониторинга, истории, управления и пользователей оформлены в тёмной электрической теме. Переключение между ними доступно в выпадающем меню по кнопке с домиком слева в верхней панели; нижняя панель навигации удалена. Заголовок приложения — «Koval Electronics». Отступы учитывают системные панели Android и вырезы экрана; при узкой ширине или увеличенном системном шрифте индикаторы напряжения располагаются вертикально, а карточки состояний перестраиваются в более компактную сетку.

На главной вкладке входное и выходное напряжение отображаются отдельными трёхразрядными лампами Nixie. Стекло, сетка электродов, металлические цоколи, ореховое основание и деревянный корпус батареи выполнены отдельными вручную подготовленными Android drawable-слоями; цифры и восемь ячеек батареи обновляются по живой телеметрии. Показания и свечение плавно меняются, а небольшие молнии остаются на фоне. Декоративные анимации останавливаются, когда приложение уходит в фон.

## Ограничения управления ИБП

Проверенная страница UPSMON PRO запрашивает только `GET /ups.txt`. Командных HTTP-запросов для теста батареи, звукового сигнала, Green Mode или ручного bypass в ней нет. Эти элементы отображаются как недоступные и не отправляют команды. Для их активации нужен официальный API/протокол производителя или поддерживаемый сервер-компаньон.

## Сборка и тесты

Откройте проект в Android Studio или выполните:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Уведомления и обновления

При каждом запуске приложение проверяет последний публичный релиз в GitHub-репозитории [`adamchderil/mevolt-ups`](https://github.com/adamchderil/mevolt-ups). Для обнаружения обновления релиз должен иметь числовой тег версии (например, `v1.13`) и APK asset с именем `mevolt-ups.apk`. Установка запускается только после явного нажатия пользователя, а Android показывает системный экран подтверждения. Для sideload-установки необходимо разрешить MeVolt UPS устанавливать приложения из этого источника.

APK каждого релиза должен быть подписан тем же ключом, что и ранее установленная версия; Android отклонит обновление с другой подписью. Ключ подписи и его пароли нельзя добавлять в репозиторий. Перед публикацией первого APK необходимо сверить его сертификат с установленной у пользователя версией.
